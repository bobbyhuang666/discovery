# Example: UI Style Discovery

**User:** Make the dashboard feel premium and technological, but not like a cheap AI template.

**Correct actions:** Inspect current brand assets, then SKETCH or PROTOTYPE rather than requesting abstract adjectives indefinitely.

**Recommendation:**

> **Recommendation:** Use restrained light or deep-neutral surfaces, strong typography, thin separators, limited accent color, and one calm hero visualization. Avoid purple neon, excessive glow, generic glass cards, and dense decorative charts. This should change only if the brand intentionally targets gaming or consumer entertainment.

Present two concrete directions and ask which trade-off is closer: airy executive editorial versus dense command center.

Record what to borrow and avoid from each reference; do not copy a reference wholesale.
