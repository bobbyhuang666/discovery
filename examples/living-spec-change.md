# Example: Living Specification Change

Current truth records `REQ-012` as active. A proposed change modifies its behavior.

1. Create `CHG-...` without editing `REQ-012` immediately.
2. Record the proposed modification and preserved invariants.
3. Implement and verify acceptance plus regression behavior.
4. Update current truth while preserving the stable ID or explicit supersession link.
5. Record the applied change ID and archive the verified proposal.
