# Example: Asynchronous Channel

**User:** Send me the remaining questions in one message because I answer through email.

Use one decision theme with up to three coupled fields, not a long cross-domain questionnaire.

Example:

> **Decision: Failure handling for the import. Recommendation:** preserve valid rows, quarantine invalid rows, and produce a downloadable error report. This avoids losing good data while keeping failures visible.
>
> Please confirm: (1) may valid rows commit when some rows fail, (2) should users be able to retry only failed rows, and (3) how long should error reports remain available?

Do not combine this with unrelated UI, pricing, and deployment questions.
