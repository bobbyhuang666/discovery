# Domain Pack: Website and UI

Load for websites, dashboards, applications, redesigns, and user-facing workflows.

## Concern slots

- primary user task and information hierarchy;
- navigation and state transitions;
- responsive and accessibility behavior;
- loading, empty, error, permission, and offline states;
- content ownership and localization;
- visual direction and exclusion rules;
- interaction feedback and motion;
- performance budget and progressive enhancement;
- analytics and conversion only when relevant;
- compatibility with existing design system.

## Common hidden requirements

- destructive-action confirmation and undo;
- keyboard and screen-reader operation;
- data density versus scanability;
- image availability and fallback;
- role-specific views;
- visual effects degrading on weak devices.

Pair with `auditors/style.md`; add stakeholder and data auditors for complex dashboards.
