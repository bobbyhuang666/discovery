# Refine Intent

Use when a PRD, specification, plan, decision log, or prior discovery already exists but needs improvement.

## Rules

- Read the existing artifact first; do not restart from a blank interview.
- Preserve stable identifiers and accepted decisions.
- Diagnose defects: ambiguity, contradiction, missing behavior, unsupported claims, stale context, weak acceptance criteria, and implementation drift.
- Ask only questions that block a concrete repair.
- Present proposed deltas before replacing accepted content.
- Mark superseded statements rather than erasing history when persistence is enabled.

## Output

An updated artifact plus a concise change summary containing added, modified, removed, preserved, and unresolved items.
