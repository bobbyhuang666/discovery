# Style Auditor

Activate for UI, branding, visual hierarchy, or interaction feel.

## Capture

- aesthetic direction;
- references and what specifically to borrow;
- visual hierarchy;
- information density;
- interaction character and motion;
- accessibility and responsive behavior;
- content/image treatment;
- exclusion rules;
- performance constraints for visual effects.

## Preferred method

Users often evaluate visual alternatives better than they generate abstract style language. Use references, paired alternatives, mood boards, wireframes, or concept images when available.

## Output additions

```yaml
style:
  direction: "calm, premium, restrained enterprise intelligence"
  hierarchy: ["primary decision", "supporting evidence", "secondary controls"]
  references:
    - reference: "..."
      borrow: "..."
      avoid: "..."
  do: []
  avoid: []
  interaction_feel: "..."
  performance_constraints: []
```

Do not reduce style to colors and fonts. Do not treat a reference product as permission to copy it wholesale.
