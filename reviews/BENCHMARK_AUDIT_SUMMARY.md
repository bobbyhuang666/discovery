# Prior Benchmark Audit Summary

The prior blind-test report provided useful qualitative signals but cannot support a product ranking because:

- API failures were scored as method failures;
- one model acted as the only judge;
- Oracle disclosures were stochastic rather than deterministic;
- many workspace scenarios withheld facts while contestants lacked workspace tools;
- Discovery received a purpose-built chat adapter while several competitors received descriptive documentation;
- downstream implementation was not executed;
- statistical significance claims were not backed by reproducible calculations;
- measured user burden contradicted the final report's claim.

Only three repeated behavior signals were accepted for v17.1: over-processing trivial requests, poor no-tool fallback, and excessive interaction complexity for lighter models.
