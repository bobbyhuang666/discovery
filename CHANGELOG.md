# Changelog

## 17.1.0 — 2026-07-27

- Added deterministic Quick Exit triage: direct, confirm-once, or full discovery.
- Added runtime capability negotiation and one-time fallback enforcement.
- Added light-model policy routing and structural output limits.
- Added state schema 4.1 with model tier, capability inventory, and fallback history.
- Added request-profile schema, CLI triage command, migration, tests, and release checks.

## 17.0.0 — 2026-07-27

- Split the portable Skill from an optional deterministic Host Runtime.
- Replaced unconditional policy loading with route manifests, policy bundles, and context budgets.
- Added code-enforced state transitions, action guards, structured events, atomic commits, lock files, and pending-event recovery.
- Added a strict LLM action contract and runtime unit tests.
- Added `pyproject.toml` and fully pinned `requirements.lock`.
- Reclassified competitor scoring as a static protocol coverage audit rather than a live benchmark.
- Added schema migration from v16 state schema 3.0 to v17 schema 4.0.
